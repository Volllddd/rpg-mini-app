# Мини‑приложение «Путь героя»

Статический Telegram Mini App: интерфейс берёт состояние персонажа и квестов из того же n8n Data Table, что и чат‑бот. Кнопки «Выполнено», перенос, привычки, кампании, экипировка и лавка отправляют действия в n8n API. Внешний вид рассчитан на мобильный экран и Telegram WebView.

## Публикация

1. Сначала импортируй `../rpg-planner-unified-n8n.json` в n8n Cloud, свяжи Telegram credential и включи workflow. Если прежний workflow этого бота активен, выключи его, чтобы два Telegram Trigger не спорили за обновления.
2. В узле `Mini App API · POST /rpg-mini-api` скопируй **Production URL**. Он оканчивается на `/webhook/rpg-mini-api`.
3. Production URL уже вписан в `app.js` в приложенном комплекте.
4. Создай публичный GitHub-репозиторий и загрузи **содержимое этой папки** в корень репозитория. В Settings → Pages включи публикацию из ветки `main`, папка `/ (root)`. GitHub Pages выдаст HTTPS-ссылку вида `https://ИМЯ.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.
5. В @BotFather выполни `/setmenubutton`, выбери бота, укажи название кнопки, например `Открыть игру`, и HTTPS-ссылку GitHub Pages.
6. Открой чат с ботом и нажми кнопку меню. Mini App должен показать тот же профиль, что и бот.

В `app.js` уже вписан твой Production URL API. Токен бота, секреты и локальная база в сайт не включены. n8n проверяет подпись initData, возраст подписи (до 24 часов) и Telegram ID владельца `8727767843`. Если мини‑приложение открыто обычной ссылкой, API не принимает запрос.

Пока в `app.js` стоит заглушка адреса API, страница показывает предпросмотр и хранит изменения только в памяти вкладки. Это нужно заменить до публикации.

## Экранные разделы

- Сегодня: отдельные списки временных квестов и постоянных привычек.
- Квесты: выполнение одним нажатием и перенос на завтра.
- Кампания: цели с четырьмя этапами и боссом.
- Снаряжение: слоты оружия, брони, плаща и реликвии, навыки и лавка личных наград.

В каталоге используется игровой портрет героя с лицом владельца по его явному согласию. При публикации на GitHub Pages портрет будет доступен публично вместе с файлами сайта.
